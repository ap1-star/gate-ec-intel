GATE EC TERMINAL — CHOOSE YOUR HOSTING FILE

FULL WEBSITE: GATE_EC_COMBINED_HOSTING_SOURCE.zip
Recommended path: extract -> upload contents to GitHub -> deploy that repository on Railway.
Keep package.json and Dockerfile at the repository root.

Railway setup:
1. Attach a persistent volume mounted at /data. Use one replica.
2. Generate an HTTPS domain.
3. Set PUBLIC_ORIGIN to that exact HTTPS origin.
4. Set SQLITE_PATH=/data/workspace.sqlite.
5. Set a new persistent random SESSION_SECRET (at least 48 characters).
6. Set RUN_SCHEDULER=true and deploy. Start command: npm start.
7. Register your own website account. No original hosted accounts or secrets transfer.
8. Owner access: run `npm run owner:lookup -- your-email@example.com` in the service shell,
   set the returned UUID as OWNER_USER_ID, and redeploy.

NETLIFY OR VERCEL FRONTEND:
Import the source repository. Build: npm run build. Output: public.
Set BACKEND_ORIGIN to your Railway backend's HTTPS origin.
Set Railway PUBLIC_ORIGIN to your final Netlify/Vercel frontend origin.
Without a backend, the frontend provides public snapshot browsing only.

FAST PUBLIC-ONLY UPLOAD: GATE_EC_COMBINED_NETLIFY_DROP.zip
Upload this prebuilt ZIP at https://app.netlify.com/drop, or extract it and drop
the folder containing index.html. This does not include a running account database
or automatic source checks. Use the source/Railway path for those features.

Email/WhatsApp/SMS/web-push delivery still needs provider configuration and consent.
Read HOSTING_GUIDE.md for exact steps, limitations and troubleshooting.
